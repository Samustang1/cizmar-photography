# Portfolio v5 — Nocturne (archív)

Táto verzia bola nasadená ako predchádzajúca podoba webu. Používateľ ju
zamietol ako „až príliš“ — dizajn bol výraznejší než fotografie a stránka
pôsobila viac ako prezentačný koncept než ako fotoportfólio.

## Čo tu je

- `index.html` — pôvodná stránka Nocturne
- `assets/css/nocturne.css` — pôvodné štýly
- `assets/js/nocturne.js` — menu, scrollspy, reveal a lightbox
- `assets/js/cal-embed.js` — lazy-load Cal.com kalendára
- `assets/img/` — favicon a placeholder

Súbory sú iba archívne. Aktuálny web je v `docs/` a tento priečinok sa
nenasadzuje.

## Prečo je tu

Aby sa k predchádzajúcemu smeru dalo vrátiť alebo ho porovnať. Nová verzia
stavia na tom, čo fungovalo — tmavý rám, čistá typografia a rezervačný
kalendár — ale fotografie dostali hlavnú úlohu.
