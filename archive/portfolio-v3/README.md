# Portfolio v3 — archív

Záloha verzie webu pred kompletným redizajnom (október 2026).

## Obsah
- `index.html` — jednostranový web (editoriálny štýl, off-white + tmavý kontakt)
- `assets/css/v3.css` — pôvodný štýl
- `assets/js/v3.js` — interakcie (sticky header, filtre, lightbox, scrollspy, reveal)
- `assets/js/v3-form.js` — pôvodná formulárová logika (FormSubmit) — už sa nepoužíva
- `assets/js/cal-embed.js` — Cal.com inline embed (používa sa aj v novej verzii)

## Poznámky
- Obsahuje odstránenú pohyblivú (marquee) sekciu.
- Kalendár: `https://cal.com/cizmar.photo/automobilove-fotenie`
