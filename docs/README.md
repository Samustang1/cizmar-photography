# Cizmar Photography — nasadzovaná stránka

Tento priečinok sa publikuje cez GitHub Actions na
https://samustang1.github.io/cizmar-photography/

Jediná stránka: `index.html` + `assets/css/photofirst.css`,
`assets/js/photofirst.js`, `assets/js/cal-embed.js`.

Fotky sú dočasne Unsplash placeholders; pri výmene ich nahraďte v
`index.html` a najlepšie uložte do `assets/img/`.

Rezervácia: Cal.com inline embed (`cal.com/cizmar.photo/automobilove-fotenie`).
